Question 1: Simple Interest Calculation using Maven and Azure Pipeline
1. Aim
To develop a Java application to calculate simple interest using the principal amount, rate of interest, and time period provided as input, build the application using Maven, and configure an Azure Pipeline to compile the source code and generate a JAR artifact.
2. Formula

SI=PRT100
Where:
P – Principal amount
R – Rate of interest per annum
T – Time period in years
SI – Simple interest

Amount=P+SI
3. Requirements
Ubuntu or Windows operating system
Java JDK 17
Apache Maven
Git
GitHub account
Microsoft Azure DevOps account
4. Procedure
Step 1: Check Java installation
Open the terminal and execute:
java -version
Check the Java compiler:
javac -version
If Java 17 is not installed on Ubuntu:
sudo apt update
sudo apt install openjdk-17-jdk -y

Step 2: Install Maven
Execute:
sudo apt install maven -y

The output should display the Maven version and the Java version used by Maven.
Explanation: Maven is a build automation tool used to compile Java source code, manage dependencies, execute tests, and package applications into JAR files.
Step 3: Create a Maven project

Step 4: Write the Java program
Open the Java source file:
nano src/main/java/com/example/App.java
Replace the existing code with the following:

package com.example;

import java.util.Scanner;

public class App {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter Principal Amount: ");
        double principal = sc.nextDouble();

        System.out.print("Enter Rate of Interest: ");
        double rate = sc.nextDouble();

        System.out.print("Enter Time Period (in years): ");
        double time = sc.nextDouble();

        double simpleInterest =
                (principal * rate * time) / 100;

        double totalAmount = principal + simpleInterest;

        System.out.println("Simple Interest: " + simpleInterest);
        System.out.println("Total Amount: " + totalAmount);

        sc.close();
    }
}
Save the file by pressing Ctrl + O, Enter, and Ctrl + X.
Explanation of the program:
The Scanner class accepts input from the user.
The principal amount, interest rate, and time period are stored in variables.
The simple interest is calculated using the formula.
The total amount is calculated by adding the principal and simple interest.
The calculated values are displayed using System.out.println().
Step 5: Configure the Maven build file
Open the pom.xml file:
nano pom.xmlnano

<project xmlns="http://maven.apache.org/POM/4.0.0"

    <build>
        <plugins>

            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-jar-plugin</artifactId>
                <version>3.4.2</version>

                    <archive>
                        <manifest>
                            <mainClass>com.example.App</mainClass>
                        </manifest>
                    </archive>
                </configuration>
            </plugin>
        </plugins>
    </build>

</project>
Save and exit.
Explanation:

version defines the project version.
maven.compiler.release specifies Java 17.
maven-compiler-plugin compiles the Java source code.

mainClass specifies the entry point of the application.

Step 9: Create the Azure Pipeline YAML file
Inside the Maven project root directory, create a file named:
nano azure-pipelines.yml
Enter the following pipeline configuration:

trigger:
  - main

pool:
  vmImage: 'ubuntu-latest'

steps:
  - task: JavaToolInstaller@0
    inputs:
      versionSpec: '17'
      jdkArchitectureOption: 'x64'
      jdkSourceOption: 'PreInstalled'

    inputs:

      ArtifactName: 'SimpleInterest-JAR'
      publishLocation: 'Container'
Save and exit.

nano src/main/java/com/example/App.java

package com.example;

import java.util.Scanner;

public class App {

    public static String checkResult(int marks) {
        if (marks >= 50) {
            return "Pass";
        } else {
            return "Fail";
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter student marks: ");
        int marks = sc.nextInt();

        if (marks < 0 || marks > 100) {
            System.out.println("Invalid marks");
        } else {
            String result = checkResult(marks);
            System.out.println("Student Result: " + result);
        }

        sc.close();
    }
}
Save the file using Ctrl + O, Enter, and Ctrl + X.
Explanation:
checkResult(int marks) accepts the student's marks.
If marks are greater than or equal to 50, it returns "Pass".
Otherwise, it returns "Fail".
The main() method accepts marks from the user and displays the result.
The program also checks whether the entered marks are within the valid range of 0 to 100.

Experiment 3: Gross Salary Calculation Using Jenkins
Aim
To develop a Java application to calculate the gross salary of an employee and use Jenkins to compile and execute the application.
Requirements
Ubuntu/Linux system or cloud virtual machine
Java JDK
Jenkins
Git and GitHub (optional, for source-code management)
Formula

GrossSalary=BasicSalary+HRA+DA
Where:
Basic Salary – basic pay of the employee
HRA – House Rent Allowance
DA – Dearness Allowance
Step 1: Install and Verify Java
Open the terminal and execute:
sudo apt update
sudo apt install openjdk-17-jdk -y
Verify Java:
java -version
javac -version
If multiple Java versions are installed, select Java 17:
sudo update-alternatives --config java
sudo update-alternatives --config javac
Step 2: Install Jenkins
If Jenkins is already installed and the dashboard is accessible, skip this step.
Install Java and Jenkins on the Ubuntu cloud VM using the official Jenkins installation instructions. Ensure the VM's firewall/security group allows:
22 – SSH
8080 – Jenkins dashboard
Start and enable Jenkins:
sudo systemctl start jenkins
sudo systemctl enable jenkins
sudo systemctl status jenkins
Open Jenkins in the browser:
http://<VM-IP-ADDRESS>:8080
For a local installation:
http://localhost:8080
Step 3: Create the Java Application
Create a project directory:
mkdir GrossSalary
cd GrossSalary
Create the Java source file:
nano GrossSalary.java
Enter the following program:
public class GrossSalary {
    public static void main(String[] args) {
        if (args.length != 3) {
            System.out.println(
                "Usage: java GrossSalary <Basic> <HRA> <DA>"
            );
            return;
        }

        double basic = Double.parseDouble(args[0]);
        double hra = Double.parseDouble(args[1]);
        double da = Double.parseDouble(args[2]);

        double grossSalary = basic + hra + da;

        System.out.println("Basic Salary: " + basic);
        System.out.println("HRA: " + hra);
        System.out.println("DA: " + da);
        System.out.println("Gross Salary: " + grossSalary);
    }
}
Save the file.
Why command-line arguments are used: Jenkins runs builds non-interactively, so the salary values are passed as arguments instead of using Scanner.

Experiment 4: Palindrome Checking Using Jenkins CI and GitHub
Aim
To develop a Java application to check whether a given number is a palindrome and configure Jenkins for Continuous Integration (CI) using a GitHub repository.
Requirements
Ubuntu/Linux system
Java JDK
Jenkins
Git
GitHub account
Step 1: Verify Java and Git
Open the terminal and execute:
java -version
javac -version

If Java or Git is not installed:

sudo apt install openjdk-17-jdk git -y
Step 2: Create the Java Application
Create a project directory:
mkdir Palindrome
cd Palindrome
Create the Java file:
nano Palindrome.java
Enter the following code:
public class Palindrome {
    public static void main(String[] args) {
        if (args.length == 0) {
            System.out.println("Please provide a number.");
            return;
        }

        int number = Integer.parseInt(args[0]);
        int original = number;
        int reverse = 0;

        while (number > 0) {
            int digit = number % 10;
            reverse = reverse * 10 + digit;
            number = number / 10;
        }

        if (original == reverse) {
            System.out.println(original + " is a palindrome.");
        } else {
            System.out.println(original + " is not a palindrome.");
        }
    }
}

Experiment 5: Deploy a Web Application Using Ansible
Aim
To deploy a web application on an Apache web server using Ansible.
Requirements
Ubuntu/Linux system
Ansible
Apache web server
Web application HTML file
Step 1: Install Ansible
Open the terminal and execute:
sudo apt update
sudo apt install ansible -y
Verify installation:
ansible --version
Step 2: Create the Project Directory
mkdir AnsibleWebApp
cd AnsibleWebApp
Step 3: Create the Web Application
Create an HTML file:
nano index.html
Enter:
<!DOCTYPE html>
<html>
<head>
    <title>Ansible Web Application</title>
</head>
<body>
    <h1>Web Application Deployed Successfully!</h1>
    <p>This application was deployed using Ansible.</p>
</body>
</html>
Save and exit.
Step 4: Create the Ansible Inventory
Create an inventory file:
nano inventory
For deploying on the same Ubuntu machine, enter:
[webservers]
localhost ansible_connection=local
Save the file.
Step 5: Create the Ansible Playbook
Create the playbook:
nano webapp.yml
Enter:
---
- name: Deploy Web Application
  hosts: webservers
  become: yes

  tasks:
    - name: Install Apache web server
      apt:
        name: apache2
        state: present
        update_cache: yes

    - name: Start and enable Apache
      service:
        name: apache2
        state: started
        enabled: yes

    - name: Deploy the web application
      copy:
        src: index.html
        dest: /var/www/html/index.html
        mode: '0644'

    - name: Verify the web application
      uri:
        url: http://localhost
        status_code: 200
Step 6: Execute the Ansible Playbook
Run the playbook:
ansible-playbook -i inventory webapp.yml --ask-become-pass
Enter the sudo password when prompted.
If using the inventory format localhost ansible_connection=local, Ansible will execute the tasks on the local machine.
Step 7: Verify Deployment
Open a browser and enter:
http://localhost
The webpage should display:
Web Application Deployed Successfully!
You can also verify Apache status:
sudo systemctl status apache2
Step 8: Verify Using Ansible
Run:
ansible webservers -i inventory -m ping
Expected output should indicate:
"ping": "pong"
Result
Ansible was installed and configured successfully. The playbook installed Apache, started the service, deployed the HTML web application, and verified that the application was accessible.
Experiment 6: Vowel or Consonant Checker Using Gradle
Aim
To develop a Java application that determines whether an entered alphabet is a vowel or consonant and build the application using Gradle.
Requirements
Ubuntu/Linux system
Java JDK
Gradle
Text editor or IDE
Step 1: Verify Java and Gradle
java -version
javac -version
gradle -version
If Java is not installed:
sudo apt update
sudo apt install openjdk-17-jdk -y
If Gradle is not installed:
sudo apt install gradle -y
Step 2: Create a Gradle Project
Create the project directory:
mkdir VowelConsonant
cd VowelConsonant
Create the Gradle project structure:
mkdir -p src/main/java
The directory structure will be:
VowelConsonant/
├── build.gradle
└── src/
    └── main/
        └── java/
            └── Main.java
Step 3: Create the Java Program
Create the source file:
nano src/main/java/Main.java
Enter the following code:
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter an alphabet: ");
        char ch = sc.next().charAt(0);

        ch = Character.toLowerCase(ch);

        if (ch < 'a' || ch > 'z') {
            System.out.println("Invalid input. Enter an alphabet.");
        } else if (ch == 'a' || ch == 'e' || ch == 'i'
                || ch == 'o' || ch == 'u') {
            System.out.println(ch + " is a vowel.");
        } else {
            System.out.println(ch + " is a consonant.");
        }

        sc.close();
    }
}
Step 4: Create the Gradle Build File
Create build.gradle in the project directory:
nano build.gradle
Enter:
plugins {
    id 'application'
}

application {
    mainClass = 'Main'
}
Save and exit.
Step 5: Build the Application
From the project directory, execute:
gradle build
Gradle compiles the Java source code and creates the build output.
Expected result:
BUILD SUCCESSFUL
Step 6: Execute the Application
Run:
gradle run
Example output:
Enter an alphabet: a
a is a vowel.
Another example:
Enter an alphabet: b
b is a consonant.
Step 7: Generate the JAR File
Execute:
gradle jar
The JAR file will be generated in:
build/libs/
To view it:
ls build/libs
Result
The Java application to identify vowels and consonants was developed successfully. Gradle was used to compile, build, execute, and package the application into a JAR file.
